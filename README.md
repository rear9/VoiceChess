# VoiceChess
## Currently in development, expect changes until 2027.
#### Experimental STT (Speech-To-Text) Voice-controlled chess system, featuring;
- Live speech parsing for the menu and gameplay
- Local play
- Play against Stockfish (difficulty presets WIP)
- Blindfold support
- Get TTS feedback for opponent moves while blindfolded
